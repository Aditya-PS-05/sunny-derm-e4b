# Sunny UI concept mockups

These boards explore a cooler, presentation-ready direction for Sunny while keeping the app's existing light surfaces, burnt-orange accent, privacy-first positioning, and Android interaction patterns.

## Boards

1. `sunny-ui-board-01-entry.png` — welcome, onboarding baseline, visual story, app lock, and PIN entry.
2. `sunny-ui-board-02-tracking.png` — overview, saved scans, scan detail, edit scan, and comparison.
3. `sunny-ui-board-03-capture.png` — capture choices, guided full-body scan, camera, review, and photo check.
4. `sunny-ui-board-04-settings-reports.png` — settings, AI model, privacy, reports, and report generation.
5. `sunny-ui-board-05-details-states.png` — report detail, reminder interval, saved-selection mode, model-download progress, and analysis result.
6. `sunny-ui-collection-preview.jpg` — contact sheet for the complete set.

## Design direction

- Soft warm-grey app canvas and white cards
- Near-black typography with restrained burnt-orange accents
- Clear hierarchy, large touch targets, and consistent rounded geometry
- Graphite presentation environment with subtle orange light and grounded device shadows
- Tracking and privacy language without diagnostic claims
